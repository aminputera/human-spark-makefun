## Run it

```sh
python3 -m http.server 8080
```

Open http://localhost:8080. No build step, external fonts, dependencies, tracking scripts, or credentials are needed. `ad.png` is a browser screenshot of `index.html`, with the referral address visible.

The replacement build uses the harness's native session log, uploaded privately to make.fun. This repository contains only public ad assets and the wallet ownership claim; private credentials and session bundles stay outside it.
